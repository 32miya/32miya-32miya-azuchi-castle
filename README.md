# 安土城さんぽ

織田信長の安土城（滋賀県近江八幡市・特別史跡）を、スマホで歩いて巡れる3D散策アプリの試作品。three.js製の単一HTMLです（「大阪城さんぽ」と同じ仕組み）。

- 時代を選ぶ（メニューの「時代」）: 現代（安土城跡） / 信長の時代（天正9年・1581年ごろの想像復元）。築城や合戦の体験ツアーはありません
- 安土山: 大手口 → 一直線の大手道（約180m、石段に石仏の転用）→ 伝羽柴秀吉邸・伝前田利家邸・伝徳川家康邸・伝武井夕庵邸 → つづら折り → 伝織田信忠邸 → 黒金門（巨石の枡形）→ 本丸 → 天主台。三の丸・二の丸（信長公本廟）。西の尾根に摠見寺（三重塔・二王門）と百々橋口道
- 天主（信長の時代）: 外観5重・内部は地上6階地下1階。天主台の南の入口から地階（穴蔵）に入り、階段で6階まで上れます
  - 地階: 石蔵（土蔵として使用）。中央の礎石が無いことから生まれた「宝塔と吹き抜け」の説（内藤昌氏）を採用
  - 1〜3階: 『信長公記』に書かれた座敷（墨絵の梅・花鳥・龍虎・竹・松など）を想定した障壁画
  - 4階: 絵の無い屋根裏の段、南北の破風口に四畳半
  - 5階: 八角の段。外の柱は朱・内の柱は金、釈迦説法と十大弟子。縁輪と高欄に出られます
  - 6階: 三間四方。内外とも金、昇り龍・降り龍の柱、天人の天井、鉄の狭間戸
  - 屋根は「青く見える瓦」（フロイス）と金箔瓦・金の鯱（出土）
  - 夜は天正9年の盂蘭盆の提灯飾り（『信長公記』）を再現
- 信長の時代だけ: 大手の三つの門と石塁、家臣の屋敷、本丸御殿（清涼殿と同じ間取り）、摠見寺本堂、城下町（楽市楽座の高札・下街道）、セミナリヨ、常楽寺港、三方を囲む内湖と丸子船
- 入れる建物: 信長の時代＝天主・本丸御殿・大手道ぞいの家臣の屋敷（羽柴秀吉邸・前田利家邸・徳川家康邸・武井夕庵邸・織田信忠邸。いずれも「伝」）・摠見寺本堂・セミナリヨ・城下の町家 / 現代＝摠見寺仮本堂・安土城天主 信長の館（6階の原寸復元。実際は南東約2km）
- 名所の写真は Wikimedia Commons から検索して表示します（撮影者・ライセンスを併記）
- 距離は実際より縮め（水平約0.6倍）、建物の配置と寸法は簡略化しています。信長の時代の姿は『信長公記』・フロイス『日本史』・発掘調査の成果に、言い伝え（「伝○○邸」など）と復元案（仮説）を合わせた想像の再現です

URLの末尾に `?era=edo` を付けると信長の時代から始まります。

公開URL（GitHub Pages を有効にした場合）: https://32miya.github.io/32miya-32miya-azuchi-castle/

## お城さんぽシリーズ共通
- 人物・旗・襖絵・床板・石垣などの素材は、シリーズ共通の `https://32miya.github.io/oshiro/common/assets/` から読み込みます（このリポジトリに同じ画像を置かない）。一覧と使い方は `32miya/32miya.github.io` の `oshiro/common/README.md`。
- 天守の窓は本当の開口にして、各階の中から外の景色が見えるようにする（シリーズ共通の作り）。
- index.html の末尾の `oshiro-portal:begin`〜`end` は「お城選びへ戻る」ボタンなので消さない。
